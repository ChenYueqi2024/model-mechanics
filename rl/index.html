绕远去领奖励划算吗？

近处终点奖励 +2，远处终点奖励 +8。先猜每步花费 0.1 时会去哪，再看训练终局。保持同一张地图和随机种子，把花费提高到 1.5 重做实验。

怎样读懂探索、奖励和回放？

所有 Q 从 0 开始。前 100 回合均匀随机探索，之后每一步有 25% 概率随机探索，其余时间选 Q 最大的动作。训练时平手随机选择；展示策略时按上、右、下、左依次打破平手，所以早期箭头可能形成循环。

每步先扣花费，进入终点的同一步再加奖励。学习率为 0.5，折扣因子为 0.95。终点之后的价值按 0 计。每回合从同一起点出发，最多采样 80 步。回放使用固定种子 42，共 400 回合。切换花费时对齐回合与步数，若原来位于回合末则对齐回合末。
