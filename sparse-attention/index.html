少连几条边，远处 token 还能被看到吗？

因果注意力只能读当前或更早的 token。全因果注意力保留所有允许的连接；滑动窗口只保留近邻。叠多层以后，一个位置可以通过中间位置间接收到更早的信息。

先做一个对照

把模式切到局部窗口，宽度设为 3、深度设为 1。再把深度增到 4，或换成「窗口 + 锚点」，比较最后一个 token 能接收哪些来源。

原理与研究练习

矩阵的行是查询，列是可能读取的位置。绿色格子代表单层允许的一对。锚点设在第 4、8、12 个位置，普通查询可以读更早的锚点，锚点查询可读整个过去。多层追踪只计算图上的可达性。真实注意力权重和表示内容还会决定信息是否被保留。

Longformer 展示了局部与全局注意力的组合；这里用因果约束做简化。实验计的是查询–键配对数，实际延迟还取决于实现。可以在固定窗口下比较不同锚点布局。
