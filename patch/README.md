# Patch Lens

同一张图里，换一组投影权重，哪些 patch 还会相似？用浏览器打开 `index.html` 即可实验，全程离线。

1. 保持默认的 16 像素边长，点左上角。启用「读颜色」，观察同一行的另外三块。
2. 保持选区，切到「读纹理」。最近邻移到同一列。两次输入像素完全相同，变化来自投影矩阵。
3. 把边长改为 8 像素。序列从 16 个 token 增加到 64 个，每个 token 仍有四维。

逐块按 RGB 展平像素得到矩阵 X，使用共享权重计算 Z = XW，偏置设为零。页面按选中行与其他行的余弦相似度绘制热图。星号表示除选区外并列最高的值，按未舍入的数据判定。两组人工权重分别计算颜色均值和周期纹理响应。实验覆盖 ViT 的输入投影步骤，真实模型中的投影通常通过训练得到。

数值检查可用 `node --test model.test.js` 运行。[Vision Transformer 论文](https://arxiv.org/abs/2010.11929)
